# Changelog

## [0.1.0] - 2026-10-20
### Added
- `SafeAreaUtility`, `SafeAreaAnchor` (safe-area UI anchoring through `DrivenRectTransformTracker`, so edit mode never dirties scenes).
- `ResponsiveCameraFitter` and pure `CameraFitMath` (keeps the reference width on tall screens).
- `MobilePointer`, `PointerState`, `PointerTracker` (touch + mouse acquisition, UI-hit exclusion).
- `IRewardedAdProvider`, `RewardedAdResult`, `RewardedAds`, `SimulatedRewardedAdProvider`.
- `ICrashReporter`, `NullCrashReporter`, `CrashReporting`.
- `MobileKitSettings` runtime settings asset.
